#anthonyniko16.github.io
----Weather app-----
This is my project for CS 351 where i created a weather app. You can type in you city and click on it and it will show you the degrees in fahrenheit, how it feels outside, the humity, wind, the high and low of the day the the 5 day forecast. I used plain HTML,CSS, and Javascript for this project

----how it works-----

- You can search any city or place in the world
- When you're typing it gives you suggestions based off of places with the lettering of what you have already typed
- Shows current temp, feels like, humidity, wind, and the high/low for
  the day
- 5 day forecast with icons for each day
- The background changes color depending on the weather and also if it's night it'll turn a darker color
- Personally I like having a dark mode on my apps so I added that for fun in the top right corner, but it only makes the screen go dark
- If you type a city that doesn't exist it'll give you an error message

----APIs----
I used OpenMeteo for this since it's free and doesn't need an API key and th geocoding from Open Meteo turn the city name into it's coordinated
